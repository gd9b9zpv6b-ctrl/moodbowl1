# 20 位朋友試用 · 預備時間表（里程碑）

唔用「第幾日／第幾週」估工；用 **做完先可以 invite** 嘅閘口。

---

## Phase A · 可以私邀（軟啟動 · 5–8 人）

**目標：** 朋友可以完整行完儀式、寫日記、睇返自己資料；唔崩、唔私隱出事。

| 閘口 | 要完成 |
|------|--------|
| A1 核心路徑 | 登入 → 儀式 → 寫日記 → 釋放 → 月曆睇返 → 匯出資料 |
| A2 私隱 | 設定「睇返／匯出／刪除」可用；政策文案對得上 |
| A3 穩定 | 裝飾可放、slider 唔拖走頁、飲品／save 唔因 DB check 失敗 |
| A4 Demo 帳 | 預備獨立試用帳（唔好共用同一個 student demo 互相洗數據） |
| A5 回報渠道 | 一個表／WhatsApp 群 · 欄位：步驟、裝置、截圖（可選）、嚴重度 |

**Invite 講法：** 「試完一條心情流程 · 有唔順講我」· 唔講未做好嘅老師 live 名單。

---

## Phase B · 擴到 ~20 人

**目標：** 同時多人用都 OK；收集「老師／輔導畫面」意見（即使仲有部分 mock）。

| 閘口 | 要完成 |
|------|--------|
| B1 Live migrations | 套 `006` 飲品 key、`008` 刪帳戶 RPC、`009` notify_teacher |
| B2 語意清理 | `notify_teacher` 取代「當 class 分享」誤解 |
| B3 FastAPI 死線 | 學生路徑唔再彈 Backend offline；admin 未接上就標「未開放」 |
| B4 老師／輔導 | 至少有清晰 mock／規則說明；或接真負面概況（優先） |
| B5 配額 | 20 個邀請碼／帳 · 角色：多數學生、2–3 老師、1 輔導 |

**Invite 講法：** 「幫我哋睇學生流同老師提示清唔清楚」· 屋企通知明確講未推出。

---

## Phase C · 試完收斂

| 閘口 | 要完成 |
|------|--------|
| C1 回報分類 | 崩壞／私隱／文案／老師規則／想要功能 |

| C3 決定下一輪 | live 跟進名單 vs 校政 backend vs parent inbox（而家先唔做） |

## 試用當日 checklist（每次開新 preview）

1. 開 Expo tunnel（唔 keep 3 小時）
2. 確認學生帳可以 save + 月曆睇到
3. 確認設定可以匯出 JSON
4. 把 link + 帳密 + 回報表一次過畀朋友
