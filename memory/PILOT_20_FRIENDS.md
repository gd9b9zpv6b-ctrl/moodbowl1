# Phase A · 20 位朋友試用（5 個角色）

**定義：** Phase A = 一次過請約 **20 人**，**5 個角色都要有人試**，之後先跟 feedback 改嘢。  
唔估「幾多日」；用下面閘口慢慢打勾。

---

## 角色同建議人數（合計 ~20）

| 角色 | 建議人數 | 主要試咩 |
|------|----------|----------|
| 學生 student | 10–12 | 儀式、寫日記、裝飾、月曆睇返、匯出／刪除 |
| 班主任 teacher | 3–4 | 老師版、負面概況、點名跟進（知到而家有 mock） |
| 輔導 counsellor | 2 | 緊急 vs 跟進規則卡、關鍵字警示（如有） |
| 家長 parent | 2 | 家長版入口、危機字提示（屋企通知未開 · 講清楚） |
| 校方 school_admin | 1–2 | 校政策／字詞設定、報告頁粗睇 |

Demo 帳（共用密碼 `demo1234` · 試用期可先用，正式 20 人最好每人獨立帳）：見 `memory/test_credentials.md`。

### 🟠 可以帶住已知限制上 Phase A（要同試用者講明）

| 項目 | 對試用者講 |
|------|------------|
| 老師／輔導跟進名單有 **mock** | 「睇版面同規則清唔清楚 · 數據稍後接真」 |
| 校政／部分 admin、探索回憶、premium | 「可能顯示未接上伺服器 · 唔係你做錯」 |
| Parent 通知 inbox | 「稍後推出 · 而家只睇得到有嘅警示入口」 |
| 刪帳戶 | 「未跑 008 前可能清到日記但登入殼仲喺」 |

### 🔴 Phase A **之後**先做（跟 feedback）

- 老師／輔導 **live** 負面名單接真日記
- 清晒其餘 FastAPI 依賴（admin／premium 全迁或關入口）
- Parent inbox／想屋企留意
- 校政設定由 AsyncStorage → 真 backend
